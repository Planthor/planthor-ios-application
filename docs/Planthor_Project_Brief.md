# Product requirements moved

Planthor's canonical product brief, roadmap, user stories, acceptance criteria, and
architecture decisions are maintained in the
[Planthor GitHub Wiki](https://github.com/Planthor/planthor-documentation/wiki).

This repository keeps only Flutter implementation documentation. Use:

- [Onboarding](ONBOARDING.md) for the development mental model.
- [Architecture](architecture.md) for feature and dependency boundaries.
- [DESIGN.md](../DESIGN.md) and its Figma references for visual implementation.
- [API](api.md) and [Authentication](authentication.md) for client integration details.

Do not add product requirements to this file. Update the Wiki and link the relevant
requirement from the implementing issue or pull request.
